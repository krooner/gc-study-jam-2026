# Google Cloud Study Jam 참여 기록 아카이브

이 저장소는 Google Cloud Study Jam 프로그램에 참여하면서 수강한 과정, 완료 여부, 학습 내용을 기록해 두기 위한 아카이브입니다.

현재 이 프로젝트는 단순한 학습 코드 저장소가 아니라, 각 프로그램별 참여 이력을 남기는 기록 보관소로 운영되고 있습니다. 각 서브폴더는 특정 기간 또는 특정 프로그램 참여 기록을 담고 있으며, 나중에 다시 확인할 수 있도록 정리되어 있습니다.

---

## 저장소 구조

- [2026_1h/](2026_1h/) : 2026년 1H Google Cloud Study Jam 참여 기록
- [2026_2h/](2026_2h/) : 2026년 2H Google Cloud Study Jam 참여 계획 및 진행 기록

현재 폴더 구조를 기준으로 보면, 이 저장소는 여러 교육 프로그램을 한데 묶어 보관하는 공간이라기보다, 각 참여 세션별 기록을 구분해서 유지하는 아카이브에 가깝습니다.

---

## 참여 기록별 구분

### 1. 2026_1h

[2026_1h/README.md](2026_1h/README.md)에는 2026년 1H 세션의 전체 참여 이력이 정리되어 있습니다.

포함 내용:

- 일정 및 기간
- 목표와 달성 여부
- 강의/Skill 목록
- Course 및 Skill Badge 진행 상황
- 완료 여부와 비고

이 폴더는 가장 상세한 참여 기록을 담고 있는 메인 아카이브입니다.

### 2. 2026_2h

[2026_2h/README.md](2026_2h/README.md)에는 2026년 2H 프로그램에 대한 계획과 진행 상황을 기록하고 있습니다.

포함 내용:

- 학습 일정
- 목표 설정
- 진행 상태
- 향후 완료 여부 추적

이 폴더는 신규 참여 세션을 시작할 때 사용할 수 있는 기록 파일 역할을 합니다.

---

## 이 프로젝트의 목적

이 저장소는 다음 가치에 초점을 둡니다.

- Google Cloud Study Jam 참여 기록을 체계적으로 보관한다.
- 각 세션별 진행 상황을 구분해 관리한다.
- 어떤 강의와 Skill을 완료했는지 추적할 수 있게 한다.
- 이후 회고, 정리, 학습 기록 확인을 용이하게 한다.

즉, 이 프로젝트는 학습 자료를 저장하는 저장소라기보다, 참여 경력과 학습 이력을 아카이빙하는 기록 저장소로 이해하는 것이 가장 적절합니다.

---

## 사용 방식

1. 각 세션별 폴더를 기준으로 참여 이력을 확인한다.
2. [2026_1h/README.md](2026_1h/README.md)에서 완료된 기록을 확인한다.
3. [2026_2h/README.md](2026_2h/README.md)에서 현재 진행 중인 기록을 관리한다.
4. 필요 시 각 참여 시기의 README를 확장해 추가 기록을 남긴다.
